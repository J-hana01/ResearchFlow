# 🔬 ResearchFlow

> ResearchFlow is an all-in-one research automation platform for researchers, clinicians, and students.

## 🚀 Features

### 📂 Data Management
- Excel/CSV Upload
- Data Preview
- Variable Dictionary Builder

### 🔍 Data Quality
- Missing Value Analysis
- Duplicate Detection
- Variable Type Check

### 📊 Statistical Analysis
- Descriptive Statistics
- t-test
- Chi-square Test
- ANOVA
- Correlation Analysis

### 📈 Visualization
- Histogram
- Box Plot
- Scatter Plot
- Heatmap

### 📑 Report Generator
- Table 1 Generator
- Data Dictionary
- Codebook
- Word Report

### 🤖 AI Assistant
- Statistical Interpretation
- Paper Summary
- Figure Legend
- Draft Writing
